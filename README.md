# Caementum Performance

Site web de coaching de course à pied (piste, route, trail), en français du Québec.

Le site se trouve dans le dossier [`caementum-performance/`](caementum-performance/). Son `README.md` explique comment le modifier, le configurer (paiement Stripe, réservation d'appel, formulaires) et le mettre en ligne.

Les anciens sites AJ NETPRO et Benax Service ont été retirés de cette branche. Ils restent récupérables dans l'historique Git.
