## Déployer
Le site est 100 % statique. Tu peux l'héberger gratuitement sur :
- **GitHub Pages** (Settings → Pages → branche `main` / dossier `/`)
- **Netlify** (glisser-déposer le dossier)
- **Vercel**, **Cloudflare Pages**, etc.
