# Images du site AJ NETPRO INC.

Dépose les fichiers suivants dans ce dossier (`images/`) **avec ces noms exacts**.
Si un fichier est manquant, le site continue de s'afficher (les visuels seront remplacés par les dégradés bleus du thème).

## Logo officiel
- `logo.png` → ton logo (le badge bleu rond « AJ » + texte « NETPRO »).
  Si ce fichier n'existe pas, un badge SVG de secours s'affiche automatiquement.

## Bannière d'accueil (hero)
- `hero-team.jpg` → photo grand format d'un membre de l'équipe en action (ex. polissage de plancher), utilisée en arrière-plan de la section d'accueil.

## Section « À propos »
- `team-window.jpg` → photo verticale (4/5) d'un technicien lavant les vitres.
- `team-floor.jpg` → photo verticale d'un technicien sur un plancher.

## Section « Notre équipe en action » (galerie)
- `team-1.jpg` → polisseuse de plancher (recommandé : la photo polissage rotatif).
- `team-2.jpg` → balayage corridor brique.
- `team-3.jpg` → lavage de vitres en hauteur.
- `team-4.jpg` → autolaveuse dans le hall.

## Avant / Après
- `before-1.jpg` / `after-1.jpg` → bureau corporatif (avant / après).
- `before-2.jpg` / `after-2.jpg` → résidence haut de gamme.
- `before-3.jpg` / `after-3.jpg` → commerce.

## Arrière-plan de la section soumission
- `bg-quote.jpg` → image d'ambiance (bureau, hall lumineux, etc.).

---

### Conseils
- Format recommandé : **JPG optimisé**, largeur 1600–2000 px pour le hero, 1200 px pour les autres.
- Outils gratuits de compression : [squoosh.app](https://squoosh.app) ou [tinypng.com](https://tinypng.com).
- Tu peux aussi remplacer n'importe quelle photo en gardant le même nom de fichier.
